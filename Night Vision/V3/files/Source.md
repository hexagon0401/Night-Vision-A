# SOURCE.MD v2 — Global Intelligence Source Registry
# Scope: Global geopolitics, defense, and security intelligence
# For AI consumption. All content in English.

## Classification Schema
- Categories: GOV | THINK | GEO | STAT | OSINT | MEDIA
- Reliability tiers: A (official gov/UN) | B (major think tank) | C (academic/congressional) | D (mainstream press) | E (local/independent)
- OSINT tier: W (web-accessible open source — valid when registered source unavailable)
- Cross-reference with RELATION.MD using Source ID

## ID Prefix Guide
- G = Government documents (any country)
- T = Think tank / research institution
- S = Geospatial / satellite data sources
- Q = Statistical databases
- U = US military posture sources (dedicated)
- W = OSINT / web-accessible open sources (fallback)
- M = Media / news
