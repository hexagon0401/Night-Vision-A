# NV Visualize — Explore

MapLibre GL JS renders the real, bundled Natural Earth v5.1.2 geography; deck.gl renders candidate clusters and optional dashed co-occurrence links. The default is an entirely synthetic case generated by the PR 3 engine, with an always-visible SYNTHETIC DATA label. No external tile/font/API endpoint or secret is required, and no live feed is connected.

Node 22+: `npm ci`, `npm test`, `npm run build`, `npm run dev -- --host 0.0.0.0`.

Open Cases or use search to choose a candidate. The evidence card opens near its sourced representative point. Pin it into an optional drawer, unpin or close it; Escape dismisses tools/evidence. Sources and Layers open one panel at a time. Unlocated records remain available through Cases and display DATA GAP; no centroid is invented. Country/actor markers are not inferred asset locations. Lines are explicitly inferred spatial co-occurrence, never observed movement. Reduced-motion preferences disable camera transitions.

`npm run test:e2e` runs actual WebGL desktop/mobile browser interactions, blocking every non-local network request. Install the official Chromium build with `npx playwright install chromium`; alternatively use an existing browser via NV_BROWSER_PATH. The managed environment validated `/usr/bin/chromium` with writable XDG cache/config paths under /tmp. CI installs official Playwright Chromium and its system dependencies.

From the root: `.venv/bin/python tools/generate_map_demo.py` rebuilds the deterministic synthetic payload. `--check` detects drift; `tools/verify_geography.py` verifies the pinned cartography. Do not manually replace the demo with unverified historical CSVs. Trace playback, scoped ZIP downloads and the archived USGS case are now available. Real historical calibration, always-on live case loading and actual Foundry enrollment imports are not certified. See deploy/README.md.
