Night Vision 운영 연결

감시 화면 · 보관된 Alpha

키는 이 화면이나 채팅에 입력하지 않습니다. 아래 두 서비스의 비밀 설정에 직접 등록하세요. 미설정 기능은 중단 상태로 표시됩니다.

1. Cloudflare 데이터베이스

첫 Worker 배포는 무료 D1 nv-monitor 생성을 요청합니다. 빌드의 API 토큰에 D1 편집 권한이 없으면 계정에서 권한을 추가하고 다시 배포하세요. 유료 Workers 플랜으로 변경하지 마세요.

기존 데이터베이스가 있다면 실제 ID를 저장소 wrangler 설정에 연결해야 합니다. 최초 스키마는 API 첫 접속 시 생성되며, 이후 데이터 파괴 작업은 자동 실행하지 않습니다.

2. GitHub 로그인 앱

GitHub → 설정 → 개발자 설정 → OAuth Apps → 새 OAuth 앱을 만듭니다. 저장소 쓰기 권한을 가진 GitHub App은 필요 없습니다.

  • 홈페이지 주소: 현재 사이트 주소
  • 콜백 주소: 현재 사이트 주소 뒤에 /api/auth/github/callback

Cloudflare → nightvision → 설정 → 변수 및 비밀에서 일반 변수 GITHUB_CLIENT_ID, 암호화된 비밀 GITHUB_CLIENT_SECRET을 등록합니다. 초기 AI 허용 사용자는 hexagon0401의 고유 ID 82876856입니다. GITHUB_ALLOWED_USER_IDS에 쉼표로 ID를 추가할 수 있습니다.

3. NIM 연결

같은 Cloudflare 실행용 변수 및 비밀에 NVIDIA_API_KEY를 비밀로 등록합니다. 무료 API 이용 가능 여부를 확인한 뒤 일반 변수 NIM_ENABLED=true를 추가합니다. 두 번째 키는 NVIDIA_SECONDARY_API_KEY입니다. 빌드 변수에 키를 넣지 마세요.

모델 설정: NIM_MODEL, NIM_REVIEW_MODEL. 로그인 후 연결 진단을 실행할 수 있으며, 한도·접근 오류가 나면 해당 모델의 당일 새 호출을 중단합니다. 모델이나 계정의 과금 설정은 NV가 변경하지 않습니다.

4. 감시 작업 연결

무작위로 긴 값 NV_INGEST_TOKEN을 생성해 Cloudflare 실행 비밀과 GitHub 저장소 → 설정 → 비밀 및 변수 → Actions의 비밀에 똑같이 등록합니다. 이 값은 공급원·분석 결과 게시 전용입니다.

GitHub Actions 비밀에 UCDP_ACCESS_TOKEN도 등록합니다. 발급은 공식 UCDP 안내에 따라 API 담당자에게 신청합니다.

GitHub Actions 일반 변수:

  • NV_WORKER_ORIGIN: 현재 사이트의 https 주소, 경로 없이
  • NV_MONITOR_ENABLED=true
  • NV_UCDP_ENABLED=true
  • MONITOR_RUNS_PER_DAY=12 — 최대 24

Cloudflare 실행 변수의 MONITOR_RUNS_PER_DAY도 같은 값으로 맞춥니다.

GitHub 예약 실행은 기본 브랜치에 있는 워크플로만 실행됩니다. 운영 PR을 검토·병합한 뒤 Actions → NV scheduled monitor → 워크플로 실행으로 첫 회차를 실행하세요. 사용자 활동이 없는 공개 저장소에서는 예약 작업이 비활성화될 수 있습니다.

5. 공식 RSS 추가

UN News는 제목·링크만 수집하고 좌표를 추측하지 않습니다. 이용 조건 확인 후 GitHub Actions 변수에 NV_RSS_ENABLED=true와 NV_RSS_RIGHTS_REVIEWED=true를 추가합니다. 다음 연결 순서는 GDELT, FIRMS입니다.

무료 운영 한도

AI는 전체 하루 40회, 계정당 직접 분석 10회, 두 번째 모델 검토 3개로 제한합니다. UCDP는 하루 500회 요청 이내입니다. 무료 공급자 한도가 더 낮으면 그 한도가 우선합니다. 연결된 Cloudflare 계정은 무료 플랜으로 유지하세요. 예산 오류는 기능 중단으로 표시하며 유료 플랜 전환을 자동 실행하지 않습니다.
