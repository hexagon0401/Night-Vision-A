# ADR 0004 — Deterministic candidates before causal interpretation

Temporal detectors use sorted prior-only samples within each entity/metric/unit series. Median/MAD uses a positive metric-unit scale floor for zero/noisy baselines; CUSUM accumulates standardized residuals in both directions with explicit drift, threshold and cooldown. UTC hour cohorts can prevent daily cycles from appearing as anomalies when enough comparable history exists. Insufficient cohorts are reported, never filled with made-up values. Exact duplicate timestamps contribute one sample; conflicting values at that instant are excluded, not averaged silently. Reported measurements can be analyzed, but inferred/scenario/disputed/unverified measurements cannot feed the baseline.

Spatial detection uses latest sourced points per entity within a bounded recent window, identical metrics/units, haversine neighbors and connected components with at least three entities. A component is not a causal relationship or a physical track; no centroid is invented. An antimeridian pair remains nearby. Symbolic anchors never enter the spatial scan. Exceeding the point budget skips the scan explicitly instead of pretending to cover all points.

All outputs are uncalibrated candidates with source-linked observations. Detector severity is a local candidate flag, not world impact; confidence/impact remain unknown. Thresholds and scale floors are configurable, not certified on real historical data. Synthetic positive/negative tests establish deterministic implementation behavior only. Held-out domain/history evaluation is required before real Alpha accuracy claims.

Graph edges distinguish declared provenance/references/counterevidence from inferred co-occurrence. Graph nodes namespace canonical record type and ID. An explicit edge budget can truncate the graph; full candidate source/observation references remain in the report/case. The API is bounded/stateless, has no collection/publication side effects, and is not a production public endpoint. The analysis CLI never overwrites existing output files. PR 4 consumes the report for map exploration; Trace playback remains PR 5.
