# ADR 0005 — Map-first Explore with auditable local geography

Use MapLibre plus deck.gl, isolated behind a MapPort for DOM unit tests. The basemap is pinned Natural Earth v5.1.2 public-domain country geometry, with original license/hash/provenance retained. This replaces the proposed initial remote tile dependency for a reproducible offline demo; OpenFreeMap/live tiles can be added later with explicit provider terms. No AI-generated map pixels or fictional coastlines enter the GIS layer.

Render a flat #050505 ocean, #080808 land and thin gray-white country borders. The four-lens user-supplied logo, pill controls, one-line footer and no automatic permanent sidebars follow the approved design. No gradients, neon, glow or terrain textures are authored. Country polygons are generalized cartography, not authoritative boundary/asset verification.

Default overlays contain only current synthetic detector candidates. Close screen-space markers cluster at an existing representative observation point, not an invented geographic centroid. A cluster opens a focused candidate choice; a candidate opens one evidence popover, with explicit user-controlled pinning. Source/Layer/Case tools are mutually exclusive. Missing latest coordinates are not filled from old samples or country centroids. Keyboard users can choose every candidate through Cases. Search, Escape dismissal, mobile layout and reduced-motion camera transitions are supported.

Candidate relations are opt-in dashed gray paths with INFERRED labelling; they do not represent physical travel or causation. Points are sourced within the explicitly synthetic input case. The default payload is engine-generated and checked for drift; readPayload refuses mixed/demo origins. Provider text is added as DOM text, not HTML. Unsafe evidence URL schemes/credentials are rejected, and synthetic source links are never fetched or presented as actual external evidence.

Trace remains unavailable until PR 5. The frontend uses a local demo, not a live API polling/public ingestion workflow. The WebGL runtime needs a compatible browser; map errors expose an explicit fallback message with Cases still available. Unit tests isolate UI state via MapPort; actual browser tests render MapLibre/deck.gl offline at desktop/mobile sizes, exercise tools/pinning and check runtime errors. A screenshot pass is not a claim of factual source verification.
