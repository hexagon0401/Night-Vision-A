# NV beta comparison

Compare three complete systems, each using its own current framework and free search. The scenario is Red Sea attacks/shipping changes during the 90 days ending at an explicitly frozen UTC/KST cutoff. Claude/GPT are run by the owner in their actual web apps with their actual High setting; never substitute an invented model/run. The NV baseline remains Nemotron 3.5 Lightning 30B (A) and Llama 3.3 70B (B), using runtime A/B secrets. No unsupported High flag is sent.

The runner performs 3 complete A-analysis/B-critique rounds (6 major calls), carries forward the preceding report and critique, records actual provider usage, prompt hash, model metadata and input hash, and allows null results. JSON contracts require all phases and known source IDs. Same completed step returns its stored output without another call; failures preserve prior steps. Daily beta bucket <=8 attempts (six major calls plus at most two bounded retries), global <=40 and shared reviewer <=3 remain atomic; exhausted runs pause and can be resumed on a later UTC day. One new run per UTC day. A/B outputs use 4096/2048 maximum completion tokens and 90-second call timeouts.

A GitHub Actions workflow manually dispatched from main obtains a short-lived OIDC workload token. The Worker verifies GitHub's RSA signature, issuer/audience/expiry, repository ID 1204033173, main ref, workflow_dispatch event and exact beta-comparison.yml workflow path. This authorizes only beta-internal routes, not public AI, login bypass or general ingest. Existing NV_INGEST_TOKEN is an optional operator alternative. Tokens never enter artifacts. No extra Cloudflare or NIM secret needs to be copied into Actions.

GET /api/v2/beta lists public runs; GET /api/v2/beta/:id returns round/status/source data. POST /api/internal/beta/start and /step require trusted workload/internal auth. Schema 0002 is additive. The Beta Lab view shows partial/complete/error states and a copyable comparison prompt. External scores stay null until actual comparator reports are supplied.

Research uses bounded GDELT queries and allowlisted official/news HTTPS documents (max 9 searches and 30 document attempts, 4 concurrent). Only short excerpts, URLs and hashes are retained; up to three redirects are accepted only after validating every destination against the public publisher allowlist; unsafe redirects, access-challenge pages, oversized responses and post-cutoff publications are rejected. Indexing is not publication. Unknown dates and older/background sources remain labelled; inaccessible content is logged, never cited as read. At least two accessible sources are required before a model report is generated. This is deliberately bounded free research, not an assertion of exhaustive web coverage.

Run `python services/worker/beta.py --prepare-only --out <fresh output>` to prepare research and the identical comparator prompt without model calls. The manual `NV beta comparison` workflow produces run.json, NV-report.md, research-audit.json, comparison-prompt.md and a submission template, even when paused. A resume ID continues completed steps without recharging them; failure retry consumes remaining daily budget. Do not count the internal critic's score as external evaluation.

External 100-point rubric: source verifiability 20, factual accuracy 20, falsifiability 20, counterevidence/gaps 15, mechanisms 10, causal timing 10, usability 5. Blind system identities before scoring, record unverified citations and publication-family uncertainty, and do not infer detector precision/forecast skill from prose quality.

Live execution remains separate from mocked tests. A successful mock proves orchestration/authorization/quotas, not real NVIDIA model access or Red Sea findings.

Structured-output recovery: the known Nemotron analyst uses documented `enable_thinking=false`, short phase reports and the existing 4096-token ceiling. Other models keep provider defaults. Failed response usage/finish metadata is retained without hidden reasoning text; a diagnostic-only failed step is never rendered as a report.
