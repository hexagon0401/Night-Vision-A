# NV2 웹 엔진 운영 및 확장

목표는 출처가 있는 자료의 이상 변화를 탐지하고, 원인 후보·반증·자료 공백을 지도와 함께 검토하는 것이다. 감지한 변화가 위협·의도·인과관계를 입증하지는 않는다.

## 실행 구성

- GitHub Actions의 기존 하루 12회 Python 감시는 UCDP 페이지 수집, 정상 자료 게시, 국가별 일별 집계, MAD/CUSUM 계열 탐지와 사례 내보내기를 담당한다. NIM 장애와 분리되어 있다.
- Worker `/api/v2/engine/investigate?event=...`는 현재 게시된 사건·국가 기준선·동일 사건 해시의 탐색 캐시로 조사 패킷을 구성한다. 정확한 보고 지점만 점으로 만들며 지역 단위 좌표는 점으로 승격하지 않는다.
- 같은 주소에 `{event_id}`를 POST하면 허용된 GitHub 세션·동일 출처 검사 후 기존 NIM 실행기, 캐시, 하루 40회 전역 예산·계정별 10회 한도를 사용한다. API A/B 키는 기존 실행용 비밀을 사용한다. NIM 실패 시 통계와 조사 패킷을 보존하며 유료 제공처로 전환하지 않는다.
- GET `/api/v2/engine/modules`는 검토한 15개 모듈의 입력·출력·핵심 절차·원본 스킬 경로를 제공한다. 실제 등록 정보는 `services/cloudflare/nv2-modules.json`이다.

## Maestro 및 15개 모듈

Maestro v0.2.0과 15개 스킬 v0.1.0의 소스를 검토했다. 이 패키지는 조사 지침이며 별도 실행 서버·검색엔진은 없다. 사이트 구현은 스킬의 완전한 원격 실행으로 표기하지 않는다. 원본 플러그인은 변경하지 않는다.

| 모듈 | 원리·출력 | 현재 웹 실행 범위 |
|---|---|---|
| Source Destructor | 문장 조건·부정·의무를 원문 인용으로 분해 | 원문·페이지 입력 필요 |
| Topic Miner | 구조적 긴장과 반증 가능한 질문 선정 | 추가 문서 필요 |
| Evidence Finder | 지지·반증 자료 및 단위 비교 | 사건 기록·통계 후보 정리, 독립 검증 미완료 |
| Source Tracker | 원출처와 복제 계보 추적 | 출처 장부 구성, 계보 미확인 표시 |
| Source Finder | 원문 검색·문서 구간 확인 | 수집기 외 자유 검색 미구현 |
| Movement Tracker | 계획·보고·관측 이동을 구분 | 역사적 위치·운항 자료 필요 |
| Source Catcher | 루머·반박을 개별 주장으로 보존 | 원문·반박 자료 필요 |
| Chrono Search | 사건·발행·수집·발효 시각 분리 | 사건 기간과 수집 시각 보존 |
| Map Pointer | 검증된 위치만 지오메트리화 | 공급원 보고 정밀도 검사 |
| Hypothesis Lab | 귀무·대안·반증 검사 | 기본 가설·검증 과제 + NIM의 제한된 해석 |
| Maplizer | 근거와 연결된 GeoJSON 생성 | 보고된 점·허용된 가져오기 자료 표시 |
| Visual Forensics | 원본·재사용·촬영 위치 비교 | 실제 원본 영상 비교 도구 필요 |
| Diplomatic Reader | 원어 발화 행위·조건 비교 | 원문 필요 |
| Corporate Tracer | 등기·지분·자금·통제 관계 분리 | 공시·지분 분모·시점 필요 |
| Outreach Prep | 중립적 검증 질의 초안 | 별도 문서 필요, 외부 발송 없음 |

선택되지 않은 모듈은 `blocked/missing_prerequisite`, 수행 범위가 제한된 검토는 `partial`로 출력한다. P0 독립 출처 충돌 검사가 미완료이면 전체 보고서는 `partial`이다. 스킬의 전체 조사 루프·자유 검색·15개 실제 독립 에이전트 실행을 구현했다고 주장하지 않는다.

## 지도·호환 형식

`지도 레이어`에서 UCDP, ADS-B 민간 항공기, AIS 민간 선박, 공개 웹캠과 Sentinel-2 촬영 범위를 독립 선택한다. 이동 후 갱신은 명시적으로 실행한다. 과거 사건과 현재 위치는 서로 독립된 맥락이다. AIS는 선박, ADS-B는 항공기이며 AIS로 비행기를 그리지 않는다. `AISSTREAM_API_KEY`가 없으면 연결 키 필요 상태가 나타난다.

메뉴의 `NV2 근거 지도 가져오기`는 `nv2-module/1.0`의 `result` 또는 `result.geojson`, `nv-investigation/2.0`의 `map` FeatureCollection을 읽는다. 각 요소에는 `properties.evidence_status`와 `properties.source_ids`가 있어야 하고 해당 ID의 HTTPS URL이 `source_ledger`에 있어야 한다. 점·선·닫힌 다각형을 검증하며 최대 2MB·500개 요소·20,000개 좌표 노드로 제한한다. JSON 구조 검사는 원출처 진실성 검증이 아니므로 가져온 지도는 별도 검증 필요로 표시한다.

현재 위치 한 점으로 항로·운항 이력·공급망·세력 경계를 생성하지 않는다. 공급망은 시점과 출처가 있는 관계 자료, 이동 경로는 시간순 역사적 관측, 세력 경계는 문서화된 영역 지오메트리가 있어야 한다. 그러한 NV2 출력 자료를 가져와 표시하는 경로는 제공한다.

## 다음 필요한 자료

1. 선박: AISStream 키 및 허용된 역사 자료를 제공해야 수집·밀도·항만 활동의 시계열 탐지로 확장할 수 있다.
2. 공급망·세력: 공개 공시·항만 통계·소유/운송 관계의 출처와 시점이 필요하다. 운항 위치만으로 화물·소유·군사 의도를 추론하지 않는다.
3. 독립 검증: 기사·원문 본문, 인용 구간, 출처 계보, 반증 자료를 별도 수집·권한 검토 후 추가해야 P0 검사를 완료할 수 있다.
4. 현재 등록한 NIM 모델이 응답하지 않으면 기존 통계 실행과 근거 장부를 사용한다. 이 경로는 AI 추론 결과와 구분한다.
