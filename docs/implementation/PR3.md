# PR 3 — Deterministic anomaly candidates and evidence graph

Stacked on PR 2 (62ee6d5). Add prior-only median/MAD and two-sided CUSUM per entity/metric/unit, optional UTC hour-of-day cohorts, and haversine connected components over recent sourced points. Null/non-direct measurements, exact duplicate samples and conflicting same-time values cannot inflate baselines. Budgets bound observations, spatial points and graph edges. Reordered input produces the same output; future samples do not change earlier temporal decisions.

Every candidate retains contributing observation/source IDs and original windows. Confidence and substantive impact stay unknown; scores are uncalibrated detector statistics, not probabilities or causes. Explicit provenance/counterevidence links and candidate co-occurrence edges remain separately typed. Internal graph IDs namespace record types to avoid cross-type identity collisions. Truncation, insufficient history and conflicting measurements are reported.

Add stateless POST /api/v2/analysis, versioned analysis contracts and generated TypeScript, plus an explicit analyze CLI that writes a validated enriched case and report without fetching/publishing. The API remains a development transport, not a production public-analysis service. Synthetic fixtures contain spike, sustained shift, stable/seasonal controls and sourced fictional points. Tests cover deterministic behavior, no look-ahead, stable/seasonal false positives, conflicts, geometry, budgets, API and CLI.

Validation: full Python suite, frontend build/tests, contract generation drift, installed CLI, legacy hashes/archives. Hosted CI is checked on the PR. Real historical calibration, real anomaly validation and detection accuracy are not established. Scale floors are expressed in metric units and require domain calibration. UCDP day-only records are not converted to invented numeric observation instants. Graph limits do not hide the complete candidate source list in the report. No scheduler, live ingestion, map UI, Trace or alerts are implemented by this change.
