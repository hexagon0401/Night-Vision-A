# PR 6 — Detached Foundry export and bounded authenticated jobs

Produce an account-free RFC4180 UTF-8 CSV ZIP with typed schema, counts, hashes, validation report, import guide, canonical retained case and lossless many-to-many link tables. Defaults exclude inferred/scenario records and recursively exclude dependent references (including claims whose counterevidence was excluded). Time filters act on real event/observation instants; unknown instants are audited. Physical coordinates exclude symbolic anchors. Tracks require explicit supported entity selection, preserve timestamps and reject conflicts; no H3 or fabricated route vertices are emitted.

Add CLI export-foundry and bounded asynchronous API jobs: Bearer authentication from NV_API_TOKEN, disabled when unset, two workers, five submissions/minute, sixteen retained jobs, five-minute expiry and private temporary artifacts. Status/download require the same authentication. The static demo downloads prebuilt observed/all bundles without credentials; custom time/track scopes use the CLI or authenticated API. No token is stored in the frontend.

Tests cover Korean/comma/quote/newline round trips, per-file hashes, deterministic archives at an explicit export time, lossless retained scope, cascading time/inference filters, track conflicts, diagnostic bundles, unsafe credential URLs, auth/disabled API, job lifecycle and expiry. Real browser tests check the static download route/options. Foundry documentation URLs were reachable, but no enrollment upload or Ontology rendering was performed. The bundle therefore never claims foundry_ready=true; structural validity is separate from rights/source truth/actual enrollment verification. No direct Foundry upload is in this MVP.
