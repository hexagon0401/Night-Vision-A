# 파워리저브 시스템 (Power Reserve)

## 표시와 수집 분리

서버는 검증된 최신 관측과 차분만 전달한다. 탭별 메모리 저장소는 지도 이동·뷰 전환 중 유지되며 디스크나 이동 이력 DB를 만들지 않는다. 지도 움직임은 자료 초기화/취소/조회 사유가 아니다. 15초 조회는 독립적으로 수행하고, 백그라운드에서는 조회와 재생을 중단한다.

기본 지연은 선박120초/항공기180초다. 자동 모드는 공급원 연결 실패 시 재생 시각을 되돌리지 않고 시계를 잠시 붙잡아 최대600초까지 지연을 쌓는다. 정상 수신이 1분씩 유지되면 목표 지연을 15초씩 기본값으로 회복하되 재생 속도는 최대1.1배다. 사용자는 기본값/5분/10분 고정 지연을 선택할 수 있다.

실제 두 관측 사이만 관측 시각 비율에 따라 구면 보간한다. 날짜변경선과 방향각 최단 회전을 처리하며 미래 예측이나 보고 속도에 따른 경로 생성은 없다. 좌표의 약1km 정밀도를 그대로 유지한다. 두 관측 간격이 선박5분/항공기2분을 초과하면 해당 구간은 보간하지 않고 마지막 확인 위치에서 대기한다. 처음에는 최근 관측을 즉시 보여주되 충전 대기로 표시하고, 뒤로 되감지 않고 재생을 시작한다. 리저브 시간은 확인된 연속 관측 구간만 계산한다.

재생 버퍼는 최대지연600초+선박300초/항공기120초까지만 보관하며, 객체당32표본/레이어10000객체/총200000표본 상한을 둔다. 원자료 신선도와 표시 재생 시각을 분리한다. 관측이 없어진 객체는 유효한 버퍼 재생이 끝나면 제거한다. 분류 철회 등 명시적 removed_ids는 즉시 제거한다.

## 렌더링과 정보창

화면 주변20%를 포함하는 후보 목록을 자료/카메라 변경 때 계산하고 이 후보만 애니메이션한다. 별도 nv-traffic GeoJSON 소스로 교통 객체만 갱신해 사건/출처 레이어를 다시 만들지 않는다. 기본 최대30fps, 후보500개 초과15fps, 2000개 초과10fps로 제한한다. 정지/충전 화면과 동작 줄이기는 1초 간격 상태 갱신만 하며 변화가 없으면 지도 setData를 호출하지 않는다.

선택한 선박의 MapLibre 팝업은 아이콘 위에 고정되고 보간 위치를 따라간다. DOM은 선택 객체가 바뀔 때 만들고 값만 갱신한다. 선명·MMSI·속도·COG/선수방향·관측/재생시각·위치 근거·리저브·출처·연결 상태를 표시한다. 선명은 AIS 제공 이름이고 없으면 미확인이다.

MMSI 등록국은 ITU 공식 https://www.itu.int/gladapp/Allocation/MIDs 의 2026-11-13 조회표(292개 MID)를 사용한다. flag_basis=itu_mid_unverified이며 실제 기국이나 선원 국적을 검증한 결과가 아니다. 특수/미확인 MMSI에서 국적을 추측하지 않는다.

## API 호환성

기존 GET /api/v2/traffic?type=vessels|aircraft 는 items 응답을 유지한다. format=delta 및 cursor를 추가하면 기존 상태 정보와 generation/cursor/mode/upserts/removed_ids/expired_ids를 반환한다. mode는 snapshot 또는 delta다. 최초 요청, 수집기 재시작, 커서 만료는 snapshot으로 복구한다. expired_ids는 최신 목록에서 빠졌다는 뜻이며 클라이언트 재생 버퍼를 바로 지우지 않는다. removed_ids는 명시적 철회로 즉시 제거한다. 변경 로그는 좌표 대신 ID/순번/작업만 8분/100000건 보관한다.

## 운영 경계

기존 무료 수집 한도·비공개 객체 정책·D1 스키마를 변경하지 않는다. 공급원 접근 실패를 버퍼가 무한히 해결한다고 표현하지 않는다. OpenSky 키는 둘 다 인식됐으나 운영 타임아웃이 남아, oauth/positions 단계를 안전한 진단 값으로 분리하고 명시적 User-Agent/Accept 헤더를 추가했다. 키 값은 응답·로그·브라우저에 포함하지 않는다.

단위 검사에는 실제 시각 보간/되감기 방지/관측 공백/만료/날짜변경선/방향0도/차분·재시작/ITU MID/10000객체의 지역 culling을 포함한다. 브라우저 검사에서 지도 이동 중 요청 불변과 아이콘 위 팝업을 검증하고 기존 회귀를 함께 수행한다. 배포 후 차분 API와 새 정적 자산을 확인하며 공급원 장애는 별도 대기 항목으로 보고한다. 롤백은 이전 Worker 버전으로 복귀하면 되고 새 DB 마이그레이션은 없다.
