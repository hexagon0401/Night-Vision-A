# 무료 교통 수집 24시간 분산

2026-11-13 공식 문서 확인:
- OpenSky https://openskynetwork.github.io/opensky-api/rest.html#api-credits : 익명400/일, 일반 인증4000/일, feeder8000/일. 전 세계 states/all은4크레딧/회. 기본 일반1000회/일(86.4초), 익명100회/일(864초). 응답 Remaining이4000을 넘는 실제 증거가 있을 때만 feeder2000회/일(43.2초)을 적용한다. 유료/라이선스 요금제로 자동 전환하지 않는다.
- AISstream https://aisstream.io/documentation : 일일 REST 호출 수 대신 이벤트 기반 WebSocket이며 계정/IP당3연결, 구독 변경초당1회 제한. 기존30분/일은 NV 서버 비용 보호 설정이다.

사용자가 무료 유지를 선택했으므로 AIS는 매시17분부터75초, 하루24회(총1800초)를 공유 수집한다. 늦거나 놓친 구간을 몰아 실행하지 않고 다음 창을 기다린다. 접속 여부와 무관하게 최초 활성화 후 DO alarm이 예약한다. 창 밖에서는 scheduled_wait와 다음 수집 시각을 제공한다. 10분 리저브가 수집하지 않는 약59분을 채울 수 없음을 UI에 명시하며 오래된 위치를 새 관측으로 표시하지 않는다. 공급원 누락 때문에 많은 선박의 실제 제공은 보장할 수 없다.

항공기는 최초 활성화 후 시청자가 없어도 예약 수집한다. 정기 호출 시각·사용 횟수·응답 Remaining을 저장하고 최신 스냅샷만1000건 단위로 저장해 수집기 재시작 시 재사용한다. 전체 관측 이력은 저장하지 않는다. 이전80회 제한과 고정120초 수집 간격을 제거했다. 실제 남은 크레딧이 부족하면 간격을 늘리고,429의 X-Rate-Limit-Retry-After-Seconds/Retry-After를 준수한다. 인증/수집 실패는 지수 백오프(최대6시간)로 재시도한다. OAuth 실패는 위치 API를 호출한 것으로 세지 않는다. 복구 후 놓친 호출을 몰아 실행하지 않는다.

API의 schedule 필드에 공급원 문서, 일일 최대 요청 수, 기본 간격, 사용 횟수, 다음 요청/수집 창을 제공한다. 브라우저15초 차분 조회와 실제 외부 공급원 호출을 구분한다. 지도는 받은 자료 중 기존 공개/선종/신선도 정책을 통과한 객체를 최대10000개까지 처리한다. 더 많은 점을 만들기 위해 사라진 위치를 보존하거나 공개 판정을 우회하지 않는다.

검증: 크레딧 산식·회차 경계·남은 예산·429 대기·무접속 alarm 수집·기존 단위/Worker/브라우저 CI. 롤백은 이전 Worker 버전이며 새 DB 마이그레이션/비밀 등록은 없다. 일반 인증1000회는 성공 보장치가 아닌 정상 공급원 접근 시의 상한이며 현재 OpenSky OAuth 타임아웃은 별도 외부 연결 문제다.
