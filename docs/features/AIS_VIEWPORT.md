# AIS 확대 화면 자동 갱신

지도 레이어 → AIS · 민간 선박을 켠다. 확대 수준 제한 없이 현재 화면을 조회하며 날짜변경선을 지나는 영역은 두 구독 영역으로 나눈다. 화면 영역(bbox)을 AISstream 구독에 전달하고, 60초 간격으로 짧은 표본을 수신한다. 지도 이동 종료 후 800ms에 다시 조회하며 이전 범위 응답은 취소한다. 연속 스트림·전 세계 전체 선박 목록이 아니다.

민간 선종과 MMSI가 매칭된 최근 선박 최대30척, 약1km 단위 위치를 표시한다. 24시간/200개 제한의 민간 선종 static cache만 재사용하며 위치 궤적은 저장하지 않는다. 위치 캐시는 기존30초 정책, 서버 공유200회/일과 동시성3 한도를 유지한다. 화면을 오래 켜면 일일 한도에 도달할 수 있으며 UI에 제한 상태를 표시한다.

관측90초 초과는 지연, 5분 이상은 위치 제거. 연결 실패 시 마지막 위치를 유효 시간까지만 유지한다. 선박 선택 시 MMSI·속도(kn)·COG/선수방향(도)·출처·관측시각·지연을 표시한다. AIS unavailable sentinel은 null이며 0kn/0도는 유효하다. 선택한 선박 표식을 확대한다. 관측 없음은 선박 부재의 증거가 아니다.

레이어 OFF·화면 종료·탭 숨김 시 진행 요청을 취소한다. 숨김 중 폴링을 중지하고 복귀 시 오래된 위치를 먼저 제거한다. 이전/동일 MMSI 응답으로 더 최근 관측을 덮어쓰지 않는다. 비정상 viewport·날짜·좌표는 거부한다. 키는 서버 AISSTREAM_API_KEY만 사용한다. 새 비밀·DB 마이그레이션·항상 실행하는 서버는 필요 없다.

온톨로지 PR5 위에 쌓는 후속 PR이며, 운영 병합·배포는 하지 않는다. 실제 공급원 수신/범위/정책에 따라 누락될 수 있다. 단위·브라우저 테스트는 합성 선박을 사용하며 실제 세계 자료로 게시하지 않는다.
