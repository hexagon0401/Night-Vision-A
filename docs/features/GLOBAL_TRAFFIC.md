# 전 세계 AIS/항공기 표시

## 기존 문제와 변경

기존 nearby는 10초 단기 수신/30척 제한이며 위치와 선종 보고가 다른 회차에 오면 매칭하지 못했다. AIS의 메시지는 공식 문서상 UTF-8 JSON 이진 프레임이며 구독 확인은 위치 자료가 아니다. 확대 제한 해제만으로는 전 세계 함대가 만들어지지 않았다.

`/api/v2/traffic?type=vessels|aircraft` → 단일 SQLite Durable Object `TrafficHub` (`TRAFFIC_HUB`)가 접속자 전체에 공유하는 자료를 반환한다. 지도 범위와 상관없이 AIS 전 세계 구독을 지속하고, 최신 위치와 민간 선종 정보를 메모리에서 합친다. 최신 위치는 5분/최대10000개, static 정보는 24시간 제한이다. 선종 미확인·군용·법집행 선박은 공개 위치에 포함하지 않는다. Class A/B 및 문서화된 extended 보고를 처리한다. 이전 위치나 항로를 생성하지 않는다.

전 세계 항공기는 OpenSky states/all로 조회한다. 공개 정기 항공 편명 기준과 유효 ICAO24/관측시각/좌표를 검사하며 기종이 없는 응답에는 기본 unknown 아이콘을 사용한다. 항공기 위치는 2분 후 제거하고 120초 공급원 캐시를 공유한다. OpenSky 익명 조회를 사용하므로 등록된 OpenSky 키는 이번 경로에 필요하지 않다. source 실패에 유료 API로 전환하지 않는다.

공급원의 수신 범위를 넘어 전 세계 모든 객체가 있다고 주장하지 않는다. 현장에서 수신 안 된 선박·정지 중 보고 간격이 긴 선박·민간 분류 미확인 선박은 빠질 수 있다. 초기 몇 분은 선종 매칭을 기다리는 warmup 상태다. 2026-11-13 실제 OpenSky 점검에서 원응답8433건/필터 통과3019건을 확인했으며, 이 수는 특정 시점의 점검 결과이지 보장치가 아니다.

## 아이콘·방향

사용자가 제공한 Night Vision AIS + ADS-B Icon Kit v1의 원본 PNG2x/SVG/분류 코드·manifest·README를 보존한다. 파일은 public/assets/nightvision에 있다. 위험도는 색으로 만들지 않는다. AIS 70대는 cargo, 80대 tanker, 60대 passenger로만 분류하며 상세 선종을 추정하지 않는다. 기종 코드도 군 임무/화물 용도를 추측하지 않는다.

MapLibre 심볼은 선박 true heading 우선, 없으면 COG, 항공기는 보고된 track으로 회전한다. 둘 다 알 수 없으면 0도 배치하되 opacity를 낮추고 상세 패널에서 미확인을 표시한다. 진행 방향과 선수 방향은 별도로 보존한다. 중첩 아이콘은 declutter하고 선택한 객체만 별도 우선 레이어로 강조한다. 화면당 동일 MapLibre canvas를 유지한다.

## 무료 운영 한도와 종료

공급원 키는 서버 비밀에만 있다. 새 키는 필요 없고 기존 AISSTREAM_API_KEY를 사용한다. AIS는 브라우저 요청 때 시작하고 마지막 AIS 요청 후 2분이 지나면 종료한다. 지도는 15초마다 서버 공유 자료를 조회한다. DO의 outgoing websocket은 hibernation 대상으로 간주하지 않는다. 무료 운영 예산을 위해 모든 접속자 합계 하루1800초/100만 프레임, 항공기 전 세계 조회80회/일을 보수적으로 제한한다. 도달하면 daily_budget 상태를 표시하며 유료 업그레이드를 하지 않는다. 무료 계정의 다른 사용량까지 보장하는 수치는 아니다.

static 최대2000개만 재시작 대비 보관하며 위치는 영속 저장하지 않는다. 연결 종료/재접속/누락/신선도 상태를 분리한다. 초기 선종 미확인은 배가 없다는 의미가 아니다.

## 배포와 되돌리기

wrangler.json에 SQLite DO binding과 traffic-v1 new_sqlite_classes를 추가한다. 기존 D1의 0004 온톨로지는 적용하거나 활성화하지 않는다. 정상 검증 후 main 빌드가 DO migration을 생성한다. 롤백 시 이전 Worker 배포로 돌아가며 DO namespace를 파괴하지 않는다. 신규 DO가 환경 권한/플랜 때문에 생성되지 않으면 setup_required/실제 배포 오류로 보고하고 성공을 가장하지 않는다.

테스트는 합성 데이터임을 명시하며 실제 세계 위치로 게시하지 않는다. 단위/실제 격리 SQLite DO/데스크톱·모바일 검사와 운영 전 세계 조회를 구분한다.
