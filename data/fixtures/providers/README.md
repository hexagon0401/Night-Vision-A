# Synthetic provider fixtures

Every JSON, CSV and XML response in this folder is handwritten synthetic data, not captured live intelligence. Event IDs, countries, titles, timestamps, measurements and coordinates are fictional. Real provider response shapes and reserved example.invalid news URLs are used to test parsing, not to assert actual source content. RSS uses fictional paths beneath the configured publisher domain; those paths are never fetched.

Replay always assigns synthetic data origin; a live response cannot share its record identity with a replay. Historical case CSVs are never used as verified fixtures. No API keys, third-party article bodies or copyrighted media are included.
